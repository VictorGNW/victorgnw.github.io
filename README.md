Achados do Lourdes

Site de achados e perdidos da EEEM Nossa Senhora de Lourdes (Pinheiros/ES), desenvolvido para a Feira de Tecnologia 2026 do curso Técnico em Informática para Internet.

O problema
Objetos perdidos na escola acabam em uma caixa ou na secretaria, sem registro. Quem perdeu não sabe se o item foi encontrado nem onde procurar.

A solução
Uma lista online dos itens encontrados, que facilita a busca e aumenta a chance de devolução.

Funcionalidades
- Lista pública de itens disponíveis, com nome, descrição, local, data e foto (opcional)
- Busca por palavra e filtros por categoria, local e itens com foto, além de ordenação
- Botão "É meu": o aluno envia um pedido de retirada com nome, turma e um detalhe que comprove a propriedade
- Acompanhamento dos pedidos pelo aluno ("Meus pedidos")
- Painel da coordenação com login por senha: cadastro de itens, análise de pedidos (confirmar ou recusar) e registro de devoluções
- Itens devolvidos saem da lista pública e ficam no histórico por 3 dias
- Tema claro, escuro ou automático, e aviso de itens novos
- Layout responsivo, pensado para uso no celular

Tecnologias
HTML, CSS e JavaScript (front-end) · Node.js (servidor) · JSON para itens e pedidos · pasta de arquivos para as fotos · localStorage/sessionStorage para preferências · Google Fonts

Observação
Os pedidos contêm dados pessoais (nome, turma), que só ficam visíveis para a coordenação. Em demonstrações, use apenas dados fictícios.
