# victorgnw.github.io
Site de achados e perdidos da EEEM Nossa Senhora de Lourdes. A coordenação cadastra os itens encontrados, com foto opcional, e os alunos pesquisam, filtram e pedem a retirada online. A coordenação analisa os pedidos e registra as devoluções. Feito com HTML, CSS, JavaScript e Node.js para a Feira de Tecnologia 2026.
